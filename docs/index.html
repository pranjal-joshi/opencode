Use OpenCode Zen models for your Home Assistant

Turn any OpenAI-compatible OpenCode Zen model into a Home Assistant conversation agent. Talk to your home, control devices, and use the free models — all with one API key.

Install Now GitHub Get an API key

Why OpenCode Zen?

OpenCode Zen is a curated AI gateway that only serves tested, verified models. This integration brings that quality to Home Assistant.

🤖 Conversation Agents

Add unlimited agents — one per model — and switch between them from Assist, dashboards, or automations.

🏠 Home Control

Let the model call tools to interact with your devices and entities, just like the official OpenAI and Anthropic integrations.

🎤 Voice Ready

Works out of the box with the Assist voice pipeline and voice assistants.

🆓 Free Models

Use the free OpenCode Zen models (like deepseek-v4-flash-free) at no cost.

📎 Attachments

Send images and PDFs along with your messages for richer responses.

🤖 AI Tasks

Generate structured data on demand with AI tasks, and attach files to guide the results.

💬 Streaming

Real-time token streaming in the conversation UI for a snappy feel.

Get started in 3 steps

  1. Grab a free API key

    Sign in at opencode.ai/auth, add billing, and copy your API key.

  2. Install the integration

    Install via HACS or manually — full instructions on the install page.

  3. Add a conversation agent

    Enter your key, pick a model, and start chatting. See the configuration page for details.
